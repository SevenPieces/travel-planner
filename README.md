# travel-planner（旅行攻略生成）

一个 Agent 技能：把"帮我规划去某地"变成一份可执行的旅行攻略。

产出包含速览、需出发前核实清单、行程总览表与路线图、每日详细行程、景点库
（经典必去 / 值得一去 / 可去可不去 / 本次不安排 四级分类，优缺点如实）、住宿方案、
交通与自驾、预算估算、打包清单、Tips 与信息来源，并可生成同名 HTML 阅读版。

关键约定：**正文中文，文件名英文 kebab-case**。

## 产出什么

| 产出 | 说明 |
|---|---|
| `<目的地英文>-<出发日期>.md` | 可编辑的攻略源文件（正文中文） |
| `<目的地英文>-<出发日期>.html` | 自包含样式的阅读版，浏览器直接打开，可打印/导出 PDF |

默认输出到 `<cwd>/travel-guides/`，例如 `bali-2099-01-01-family-trip.md`。

## 环境要求

- **Node.js 18 或更新**（只有 `scripts/md2html.mjs` 需要；其余是给 Agent 的流程说明）
- 支持技能的 Agent 环境（DeepSeek Harness、Claude Code 等），且可联网调研与核实
- 无 npm 依赖，无需安装任何包

## 安装

克隆到你的技能目录，目录名与 frontmatter 里的 `name:` 保持一致：

```sh
git clone <repo-url> ~/.dsh/skills/travel-planner
# Claude Code
git clone <repo-url> ~/.claude/skills/travel-planner
```

## 用法

直接用自然语言提出需求即可，例如"做一份西双版纳 6 天 5 晚的家庭旅行攻略"。
技能会先收集行程简报（目的地/日期/成员画像/交通/住宿/行程原则/额外要求），
再并行调研、按固定契约撰写、过质量门自查。

### 直接运行脚本

```sh
node scripts/md2html.mjs <攻略.md> [输出.html]
```

省略输出路径时，在同目录生成同名 `.html`。支持的图块：

| 图块 | 效果 |
|---|---|
| ```map | 真实地图（Leaflet + 高德瓦片，需联网）；`@overview` 首行表示仅总览图；无坐标时退化为 ```route 示意 |
| ```route | 节点式动线示意 |
| ```video | 视频卡片（B 站嵌入播放器 + 链接兜底） |

另支持 Markdown 图片 `![alt](url)`、裸 URL 自动转链接、斜体图注，
以及**本地相对路径图片自动 base64 内嵌**（HTML 可离线看图）。

## 目录结构

```
SKILL.md                         技能本体：收集输入、调研协议、输出契约、质量门、复用旋钮
scripts/md2html.mjs              Markdown -> 样式化 HTML（无依赖）
examples/sample-family-trip.md   完整执行示例（西双版纳 6 天 5 晚家庭游）
examples/sample-family-trip.html 该示例的 HTML 渲染版
```

## 调研与质量约定

- 四轨并行调研（核心景点组①②、在地深度体验、后勤），信息以近两年为准。
- 每个关键事实要么附来源链接，要么明确标注"需出发前核实"，二者必居其一。
- 优缺点如实：每个推荐地点都有缺点/坑，含争议与负面评价，不因名气大而回避。
- 体力强度分级齐全，并为受限成员（老人/低强度/幼儿）给出低强度替代方案。
- 视频需覆盖正反两面测评（【推荐】向 + 【避雷/批判/客观/争议】向）并标注方向标签；
  某地点找不到批判向素材就如实标注，不硬凑。
- 实景图与视频必须真实存在、严格对应地点、标注年份与来源许可；
  绝不使用近似图、AI 图或占位图。
- 路线图只覆盖目的地内动线，不含出发地往返机场的航班段。
- 预算分项与合计自洽，日期星期用 `date` 命令核实。

## 说明与限制

- 地图图块依赖联网加载 Leaflet 与高德瓦片；离线时请改用 ```route 示意。
- 时效性信息（门票、班次、价格、限流公告）无法保证长期有效——这正是"需出发前核实清单"存在的原因。
- `examples/sample-family-trip.*` 中的出发地、日期与出行人构成为占位信息，仅用于校准格式与详略。
- 若用户要求保留图片，按 Wikimedia Commons 核验 + 年份/许可标注 + base64 内嵌的标准执行。
